# APPENDIX B — PERMISSION CATALOG (ENDPOINT → PERMISSION)

Permissions are declared in code and bound to routes (Chapter 04 §4.4). Format: `module.resource.action` — scope kind in brackets: **[G]** global, **[B]** branch, **[W]** warehouse, **[O]** own records. Sensitivity: *(E)* elevated, *(C)* critical. `read` is implied by every other action on the same resource. This appendix is regenerated by `php artisan permissions:export-md` after `permissions:sync`; the list is the release-1 baseline.
